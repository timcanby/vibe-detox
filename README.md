# Vibe Detox

**Too much vibe coding. Time to remember how this stuff actually works.**

Vibe Detox is a personal knowledge-rebuilding project for developers who have become a little *too* comfortable letting AI write the code.

AI-assisted development is incredibly powerful, but there is a downside: when implementation becomes effortless, it is surprisingly easy to forget the fundamentals behind what we are building.

This repository is my attempt to fight that decay.

The goal is not to stop using AI. It is to make sure I can still understand, explain, design, debug, and implement things **without depending on it**.

Topics may include:

* Data structures and algorithms
* Computer science fundamentals
* Mathematics
* Backend engineering
* Databases
* Networking
* Operating systems
* Distributed systems
* Software architecture
* Machine learning and deep learning
* Optimization
* System design
* Implementation from scratch

Whenever possible, exercises follow a simple rule:

> **Try from memory first. Use AI later.**

The process is:

1. Explain the concept from memory.
2. Implement it without AI assistance.
3. Identify what I forgot or misunderstood.
4. Relearn the underlying theory.
5. Reimplement it cleanly.
6. Document the lessons learned.

This is not an anti-AI project.

It is an **anti-skill-decay project**.

Use AI as a tool, not as a replacement for understanding.

**Detox the vibe. Rebuild the fundamentals.**
