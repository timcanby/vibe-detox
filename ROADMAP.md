# Roadmap

Vibe Detox is early-stage. Here's where we're heading.

## Now

- [x] Define the standard concept template
- [x] Establish domain folders
- [x] Contribution guide and issue templates
- [ ] Seed 10–20 foundational concepts across domains
- [ ] Define label taxonomy (see below)

## Next

- [ ] Curated "learning paths" — ordered sequences through a domain
- [ ] Cross-topic dependency graph (`## Related topics` becomes links)
- [ ] Glossary of terms that show up across multiple concepts
- [ ] Diagram conventions / visual style guide

## Later

- [ ] Automated checks: every doc passes the template linter
- [ ] Translations (中文, 日本語, Español, …)
- [ ] Community-curated "forgotten fundamentals" lists per role (backend, ML, frontend, …)

---

## Label taxonomy

| Label | Use |
|---|---|
| `forgotten-fundamental` | A topic developers increasingly rely on without understanding |
| `domain: networking` etc. | Domain classification |
| `good first issue` | Welcoming entry point for new contributors |
| `needs-diagram` | Concept would benefit from a visual |
| `needs-example` | Concept needs a runnable or concrete example |
| `needs-references` | Concept lacks primary sources |
| `correction` | Fix to existing content |
| `discussion` | Open question about scope or approach |
